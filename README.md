# 💰 AI-Powered Expense Tracker

A full-stack expense management application built with **Java, Spring Boot, PostgreSQL, and AI**.

The application allows users to record expenses, manage monthly budgets, analyze spending patterns, generate reports, and receive AI-powered expense insights.

## 🚀 Live Demo

**Live Application:** https://expense-tracker-0if5.onrender.com

**GitHub:** https://github.com/GayatriDhore/expense-tracker

## ✨ Features

* Add and manage expenses
* Expense history with filtering and sorting
* Category-wise spending analysis
* Monthly spending analytics
* Monthly budget management
* Remaining budget calculation
* Smart saving suggestions
* Spending insights
* AI-powered expense analysis
* Automatic expense categorization using AI
* AI-generated spending advice
* CSV report export
* PDF report export
* PostgreSQL database persistence
* RESTful APIs
* Docker-based deployment
* Cloud deployment using Render

## 🤖 AI Expense Analyzer

The application includes an AI-powered expense analyzer.

Users can enter natural-language descriptions such as:

> I spent 450 rupees on pizza

The system can analyze the description and provide:

* Expense category
* Suggested title
* Expense type
* Explanation
* Spending advice

## 🗄️ Database

The application uses PostgreSQL in production.

JPA/Hibernate is used for database persistence and entity management.

## 🔌 API

The backend exposes REST endpoints for:

* Expense management
* Budget management
* Dashboard analytics
* AI expense analysis
* CSV export
* PDF export

## 🐳 Deployment

The application is containerized using Docker and deployed on Render.

The production database is hosted using PostgreSQL.
